# PPLAB4VAR13

Telegram-бот для получения случайных фактов по выбранной теме. Лабораторная работа, вариант 13.

## Возможности

- Получение случайных фактов по темам: математика, даты, годы и общая информация.
- Выбор тем и сохранение избранных категорий.
- Получение фактов из избранных категорий.
- Использование локальных фактов, если внешний API недоступен.

## Используемые технологии

- Python 3.10+
- aiogram
- requests
- python-dotenv
- SQLite
- JSON

## Установка и запуск

1. Установите Python версии 3.10 или новее.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корневой папке проекта, рядом с `main.py`.
4. Добавьте в `.env` токен Telegram-бота:

   ```env
   BOT_TOKEN=токен_вашего_бота
   ```

5. Запустите бота:

   ```bash
   python main.py
   ```

## Команды бота

- `/start` — начало работы и список команд.
- `/fact` — получить случайный факт.
- `/theme_fact` — выбрать категорию факта.
- `/fav` — выбрать и сохранить избранные категории.
- `/fav_fact` — получить факт из избранных категорий.

## Получение фактов

Бот обращается к API `www.number-trivia.com`. Если запрос не удаётся выполнить или API возвращает некорректные данные, бот использует локальные факты из `core/fallback_facts.json`.

## Хранение данных

Избранные категории пользователей сохраняются в базе SQLite `bot_data.db`. База создаётся автоматически при запуске программы.

Токен бота хранится в `.env`.

## Запуск тестов

Для установки инструментов разработки выполните:

```bash
pip install -r requirements-dev.txt
```

Запуск всех автоматических тестов:

```bash
python -m pytest -v
```

Тесты проверяют HTTP-клиент с помощью моков, загрузку локальных фактов и выбор источника фактов. Реальное подключение к API и токен Telegram для них не требуются.
